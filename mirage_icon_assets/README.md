# Mirage Icon Assets

Emerald/forest visual identity for the Mirage application.

## Primary
- mirage-icon-dark.svg — scalable dark app icon
- mirage-icon-light.svg — scalable light app icon
- mirage-mark-transparent.svg — transparent gradient mark
- mirage-mark-white.svg — monochrome white mark

## PNG sizes
Dark/light icons: 1024, 512, 256, 128, 64, 48, 32, 16 px.
Transparent/white marks: 1024, 512, 256, 128, 64, 32, 16 px.

## Web
- favicon.ico — 16/32/48/64/128/256 px multi-size favicon
