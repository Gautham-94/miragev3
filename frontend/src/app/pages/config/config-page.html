Detectors

Disable a detector to stop its process from running entirely -- frees the memory/CPU it would otherwise hold idle. Any camera still routed to a disabled detector simply won't detect until reassigned or it's re-enabled. Worker count controls how many independent copies of that detector run at once. Cameras routed to this detector share one queue across all its workers, so whichever worker is free picks up the next request -- no camera is ever pinned to a single worker. Manage models on the Detectors page.

Open-vocabulary search

Controls the OWLv2 worker process that powers free-text Queries (e.g. "person carrying a red backpack"). It's a large model (~600 MB) kept resident in memory whenever this is on -- disable it to free that memory without deleting or disabling your saved queries; they'll simply stop being checked until this is turned back on.
